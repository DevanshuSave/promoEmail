# Automated Promo Email Agent

This project is an autonomous agent that fetches promotional emails, analyzes them, ranks by expiry, and sends notifications.

## System Design Diagram

![Automated Promo Email Agent](docs/automated_promo_agent.png)

## Features
- Fetch emails from Gmail
- Analyze text and images for promotions
- Extract expiry dates
- Rank promotions by urgency
- Send notifications via email, Slack, or desktop alerts
- Autonomous periodic checking
